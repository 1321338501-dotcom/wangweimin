实现要点

  • touchstart 记下起点横坐标，touchend 用 changedTouches[0] 算横向位移。
  • 阈值 40px：短距离误触不切换；纵向位移大于横向时视为滚动，也不切换。
  • 冷却 300ms：快速连滑只响应一次，不会一次跳两张。
  • 容器用 touch-action: pan-y：横向手势归代码，纵向仍交给浏览器滚动页面。
  • 切换用 transform: translateX + transition: .3s，滑到边界弹提示。
wwm_stage.addEventListener('touchstart', function (e) {
  if (wwm_locked) return;                       // 冷却中
  wwm_startX = e.touches[0].clientX;
  wwm_startY = e.touches[0].clientY;
}, { passive: true });

wwm_stage.addEventListener('touchend', function (e) {
  var wwm_t = e.changedTouches[0];              // 抬手必须用它
  var wwm_dx = wwm_t.clientX - wwm_startX;
  var wwm_dy = wwm_t.clientY - wwm_startY;

  if (Math.abs(wwm_dx) < 40) return;            // 算点击，不切换
  if (Math.abs(wwm_dy) > Math.abs(wwm_dx)) return; // 纵向滚动，不切换

  wwm_locked = true;                            // 加锁，300ms 后释放
  setTimeout(function () { wwm_locked = false; }, 300);

  wwm_go(wwm_dx < 0 ? 1 : -1);                  // 左滑下一张，右滑上一张
}, { passive: true });

验收自查

  • ① 短距离误触（小于 40px）不会切换 —— 已用阈值拦截。
  • ② 快速连续滑动不会跳两张 —— 已用 300ms 冷却加锁。
  • ③ 手机上拖动时页面不会跟着上下滚动 —— 容器已设 touch-action: pan-y。
手机上左右滑动卡片即可切换；电脑上可用下方箭头按钮或设备模式模拟触摸。

如何保证"缩放不跳"

  • 缩放前后都锚定同一个屏幕点：捏合时取两指中点，双击时取点击位置。
  • 比例变化时同步修正位移：tx₁ = sx − (sx − tx₀) × (s₁ / s₀)，让锚点下的图像内容保持不动。
  • 位移用 px、坐标统一用 clientX/clientY，不与 pageX 混用。
  • 捏合与拖动时关闭 CSS 过渡（保证跟手），只在双击、重置、回弹时开启 0.25s 过渡。
  • 每次变换后按边界夹紧：maxTx = (图宽×倍数 − 容器宽) / 2，1x 时归零。

核心代码

// 捏合：以两指中点为基准缩放
var wwm_ratio = wwm_dist(e.touches[0], e.touches[1]) / wwm_startDist;
var wwm_next = wwm_clamp(wwm_startScale * wwm_ratio, 1, 4);

// 锚点（相对容器中心）
var wwm_sx = (e.touches[0].clientX + e.touches[1].clientX) / 2 - wwm_cx;
var wwm_sy = (e.touches[0].clientY + e.touches[1].clientY) / 2 - wwm_cy;

// 让锚点下的内容不动
wwm_tx = wwm_sx - (wwm_sx - wwm_startTx) * (wwm_next / wwm_startScale);
wwm_ty = wwm_sy - (wwm_sy - wwm_startTy) * (wwm_next / wwm_startScale);

wwm_scale = wwm_next;
wwm_clampPos();     // 边界夹紧
wwm_apply();        // 写入 transform

验收自查

  • ① 缩放以两指中心为基准，图片不会"跳走" —— 已用锚点公式修正位移。
  • ② 缩放到边界有限制 —— 倍数夹在 1～4，位移按图与容器尺寸夹紧。
  • ③ 1x 时不能拖出边界 —— 1x 时位移强制归零。
  • ④ 缩放后旋转屏幕不丢失状态 —— 监听 resize / orientationchange 重算边界并保留倍数。

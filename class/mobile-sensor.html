正在检测设备传感器…

为什么必须做降级

传感器事件不是所有设备都有：电脑浏览器没有加速度计、部分安卓机权限被关闭、iOS 13+ 还要用户手动授权、浏览器也可能直接不派发 devicemotion。如果不写降级分支，页面就只剩一句"摇一摇"却永远没有反应，用户会以为页面坏了。

  • 先判断 'DeviceMotionEvent' in window，不支持就直接提示并给按钮。
  • 监听后设一个 1.2s 的"看门狗"：期间没收到任何事件，就视为不可用。
  • 降级按钮走同一套抽签逻辑，保证功能不缺失。

核心代码

// 1. 能力检测
if (!('DeviceMotionEvent' in window)) wwm_fallback('当前设备不支持');

// 2. iOS 13+ 需要用户点击后授权
if (typeof DeviceMotionEvent.requestPermission === 'function') {
  wwm_permitBtn.onclick = function () {
    DeviceMotionEvent.requestPermission().then(function (wwm_state) {
      if (wwm_state === 'granted') wwm_listen();
      else wwm_fallback('未获得传感器权限');
    });
  };
}

// 3. 摇动判定：合成加速度 > 18，冷却 1.5s
function wwm_onMotion(e) {
  var wwm_a = e.accelerationIncludingGravity;
  if (!wwm_a) return;                                  // 没有数据
  var wwm_mag = Math.hypot(wwm_a.x || 0, wwm_a.y || 0, wwm_a.z || 0);
  var wwm_now = Date.now();
  if (wwm_mag > 18 && wwm_now - wwm_last > 1500) {
    wwm_last = wwm_now;                                // 进入冷却
    wwm_draw();                                        // 抽一道菜
  }
}

accelerationIncludingGravity 包含重力（静止约 9.8），适合判断"晃动幅度"；acceleration 已扣除重力，静止时接近 0。摇一摇用前者更稳。

验收自查

  • ① 一次摇动只触发一次 —— 1.5 秒冷却。
  • ② 没有加速度传感器时显示"不支持"并给出降级按钮，不报错、不白屏。
  • ③ iOS 上通过按钮触发 requestPermission()。
  • ④ 能讲清 accelerationIncludingGravity 与 acceleration 的区别。
